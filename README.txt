THE MERIDIAN SWAP
Two players. One device. One case.

START HERE
1. Extract the ZIP (choose Extract All / Unzip).
2. Open THE_MERIDIAN_SWAP, then open index.html in your browser.
3. Put the device between the two players.
4. Follow the game instructions. Look away during your partner's turn.

Allow 30–45 minutes. No printer, host, sound or internet connection is needed.
Everything is inside index.html. You do not need to install anything on a
computer. Do not open the file inside the ZIP or in a document preview.

DEVICES
Use a desktop or laptop browser with JavaScript enabled. The layout also
adapts to small screens, but phones differ in how they open downloaded HTML.
On Android, choose a browser if your file manager offers one.
iPhone/iPad Files previews may not run the game. Use a computer for this
offline edition if the Start case button is missing or does not respond.
There is no guaranteed app-free local-file opening route on every phone.

SAVING
Progress saves automatically when your browser allows it. Keep index.html
in the same folder and reopen it in the same browser, then choose Continue
game. Moving the file, clearing browser data or private browsing may lose
progress. A warning appears if saving is unavailable: keep that tab open.
Restart case asks before clearing your progress.

PLAYING
You are both detectives. Neither is secretly the culprit.
Read your evidence privately, hide it, and pass the device.
Describe what you noticed before showing the card to your partner.
Use Reopen my evidence to revisit only the cards you have already seen.
Three rounds lead to a joint accusation and a step-by-step reveal.
Hints are optional. Notes are optional. There is no timer or penalty.

PRIVACY
Names and notes stay in this browser. Nothing is sent anywhere.
Use Hide this screen or Pause / menu before putting the device down.
The game hides private evidence when it loses focus; still make sure your
partner looks away before you show a card. Avoid source view or developer
tools while playing: this offline game cannot conceal its files from inspection.

This is one complete, fixed mystery. Once you know the solution, replaying
will not give you a new case. Share the experience, not spoilers.
